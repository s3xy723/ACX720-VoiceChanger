固件：F103 全 SPI 音频桥（FPGA→MCP4922，无 I2S 方案）烧录说明
版本：v1.0  生成日期：2026-10-15  目标芯片：STM32F103C8T6

一、文件清单
  firmware.hex   —— Intel HEX 格式，ST-Link Utility / STM32CubeProgrammer /
                    Keil / J-Flash 都能直接认，推荐用这个烧
  firmware.bin   —— 裸二进制，起始地址 0x08000000（给需要 bin 的工具用）
  firmware.elf   —— 带符号，给调试器（如用 J-Link/GDB 调试时加载）
  main.c / startup.c / stm32f103c8.ld / build.sh —— 完整源码，可复现编译
  大小：Flash 占用 2148 字节（64K 的 3.3%），零警告编译
  2026-10-20 修复：64 MHz 下必须设 FLASH_ACR 2 等待周期，否则 HardFault

二、烧录方式（任选其一）

  方式 A：ST-Link Utility（最常用）
    1. ST-Link 接板子 SWD：SWDIO→PA13，SWCLK→PA14，GND→GND，3.3V→3.3V
    2. 打开 ST-Link Utility → Target → Connect Under Reset
       （Blue Pill 若连不上：BOOT0 跳线拨到 1 再插拔一次 USB）
    3. File → Open file → firmware.hex
    4. Target → Program & Verify
    5. 烧完把 BOOT0 拨回 0，重新上电

  方式 B：STM32CubeProgrammer
    1. 右侧选 ST-LINK，端口 SWD，Connect
    2. Erasing & Programming 页选 firmware.hex，Start Programming
    3. BOOT0 拨回 0，重新上电

  方式 C：串口 ISP（手里没有 ST-Link 时）
    1. USB-TTL 接 PA10(RX)/PA9(TX)/GND，BOOT0=1、BOOT1=0，重新上电
    2. 用 Flash Loader Demonstrator 或 STM32CubeProgrammer（UART 模式，
       波特率 115200）烧 firmware.hex
    3. 烧完 BOOT0 拨回 0，重新上电

  方式 D：ST-Link + OpenOCD（本工程已配好，推荐）
    1. 双击 tool\安装STLink驱动.bat（首次，需要管理员/UAC）
    2. 双击 tool\烧录STM32.bat
       它调用 tool\openocd\bin\openocd.exe，自动 program + verify + reset
    3. 看到 "** Verified OK **" 即成功
    4. 手动命令：
       tool\openocd\bin\openocd.exe -f interface/stlink.cfg ^
         -f target/stm32f1x.cfg -c "program {固件路径} verify reset exit"

三、上电后的预期行为（验收）

  1. 【不接 FPGA】喇叭出 440 Hz 正弦自检音（左右同相同幅，约 0.61 V 峰值）
     —— 这是故意的：DAC→RC→PAM8403→喇叭整条模拟链路可以先单独验掉。
     音量过小/过大用 PAM8403 电位器调。
  2. 串口 PA9(TX)→USB-TTL RX，115200-8-N-1，每 500 ms 一行：
        mode=TEST(440Hz) words/s=0 fs=0 ovr=0      ← 没接 FPGA 时
        mode=PASS words/s=48828 fs=24414 ovr=0     ← 接上 FPGA 后
     fs 稳定在 24414 附近（±几十 Hz）、ovr 恒 0 = 链路健康。
  3. FPGA 位流一来（2 MHz SPI、每个 CS̄ 低电平一个 16 位字），自动切
     PASS 模式直通；FPGA 停发 1 秒后自动切回自检音。
  4. 左右声道判定靠 PA4 的 EXTI4 下降沿，插反了只会左右互换，不会坏。

四、引脚占用（与《README_接线指南.md》一致）
  收 FPGA：PA5=SCK  PA4=CS̄(NSS+EXTI4)  PA7=数据   （SPI1 从机，2 MHz）
  发 DAC： PB13=SCK PB15=SDI PB12=CS̄ PB0=LDAC̄   （SPI2 主机，4 MHz）
  调试串口：PA9=TX（115200）
  悬空不用：PA6（SPI1 MISO，单向接收）
  MCP4922 侧：SHDN̄(10脚)必须接 3.3V，VREFA/VREFB 接 3.3V，AVSS 共地

五、常见问题
  - 连不上 SWD：检查 BOOT0；按住板上 RESET 再点 Connect（Connect Under Reset）
  - mode 一直是 TEST：FPGA 侧还没换 spi_mirror_tx 位流，或三根线没接/没共地
  - fs 有数但无声：先量 MCP4922 VOUTA/VOUTB 静音中值应为 1.65 V；
    再查 SHDN̄(10 脚)是否接了 3.3V（悬空=关断，输出高阻）
  - 有声但左右乱跳：查 PA4 与 FPGA CS̄ 的连线，示波器看每 20.5 µs 一个低脉冲
