## 为什么装在用户级

文件夹版 EXE 的解冻解释器是 Python 3.12，`local_ai._torch_search_paths()`
会优先找：

1. `site.getusersitepackages()` → `%APPDATA%\Python\Python312\site-packages`
2. `%APPDATA%\Python\Python3xx\site-packages`
3. `C:\Python3xx\Lib\site-packages`

装到用户级后，源码和 EXE 都能直接 `import torch / demucs`。

## 首次下载权重被墙的处理

`local_ai._can_reach()` 原来只做 TCP+TLS 握手；实测
`huggingface.co` 能握手但 HEAD 返回 **502**，旧代码会误判"能连"，
于是不切镜像，demucs 重试 5 次后失败（界面表现就是一直转圈）。

现在改成检查 HTTP 状态码：2xx/3xx 才算通，502/403 一律判为不可达。
官方不通时自动把 `HF_ENDPOINT` 切到 `https://hf-mirror.com`。
本机实测：

```
huggingface.co   -> False (502)
hf-mirror.com    -> True
```

模型已缓存，所以日常运行**不需要联网**。

## 重新安装的命令（换机/重装时用）

```bat
set PY=C:\Users\Administrator\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\python\python.exe

rem 1) torch + torchaudio（CUDA 12.8）
%PY% -m pip install --user torch==2.11.0+cu128 torchaudio==2.11.0+cu128 ^
  --index-url https://download.pytorch.org/whl/cu128 ^
  --extra-index-url https://pypi.org/simple

rem 2) demucs
%PY% -m pip install --user demucs

rem 3) 验证
%PY% -c "import torch,demucs; print(torch.__version__, torch.cuda.is_available())"
```

> 2.75 GB 的 torch 轮子单连接下载只有 ~0.6 MB/s。本工程用
> `tool/parallel_download_torch.py` 做 8 路 Range 并行下载，再本地安装。

## 自检 / 使用

```bat

```

界面里选「分离 × 计算机本地模型（demucs）」，参数框会显示
“本地 AI 环境：demucs 可用，CUDA 可用”；文件模式直接跑 GPU。
首次调用有约 10~17 秒模型加载/CUDA 初始化，之后单块推理很快。

## 注意

- **不要**把 torch/demucs 打进 EXE：cu128 全套 4 GB+，且启动解压极慢。
  现在 EXE 只带 `timeit`、`pickletools` 等 torch 需要的标准库垫片，
  AI 依赖从用户 site-packages 加载。
- 如果换到没装 torch 的电脑，AI 模式会自动置灰并提示安装，不会崩。
- 模型权重约 80 MB，已在本机缓存；删掉缓存后首次运行会重新走镜像下载。
