# 音频输出路由：从播放器到单片机上的音响

> 2026-10-21 实测（本机 Administrator / Windows 11，COM4 在线）

## 1. 结论先行

**接在单片机上的那只音响，在 Windows 里没有设备名。** 它不是 USB 音频设备，
声卡只存在于 STM32 的 DAC（MCP4922）之后，PC 枚举不到它，所以"设备管理器 /
声音设置"里永远找不到"某某音响"。

PC 侧真正要选的设备是 VB-Cable 的**播放端**：

```
CABLE Input (VB-Audio Virtual Cable)
```

桥接程序再从它的录音端 `CABLE Output` 把声音取走，串口送给 FPGA → STM32 → DAC → 音响。

## 2. 完整链路

```
上位机 / 内嵌播放器
      │  输出设备选 CABLE Input
      ▼
VB-Audio Virtual Cable（虚拟声卡，内核里把 Input↔Output 对接）
      │  录音端 CABLE Output
      ▼
tool/fpga_audio_bridge.py        （由 tool/启动FPGA声卡桥.bat 拉起）
      │  24.414 kHz / 16 bit 帧，UART
      ▼
COM4  USB-SERIAL CH340（ACX720 板载，不是 STM32 的 USB-TTL）
      │
      ▼
FPGA（uart_audio_rx → spi_mirror_tx）
      │  SPI
      ▼
STM32F103 → SPI2 + DMA → MCP4922 双通道 DAC → PAM8403 功放 → 音响
```

## 3. 本机设备实测（sounddevice 枚举，2026-10-21）

| 用途 | 设备名 | PortAudio 索引 | Host API |
|---|---|---|---|
| **送到单片机音响** | `CABLE Input (VB-Audio Virtual Cable)` | **6** | MME |
| 同上（低延迟） | `CABLE Input (VB-Audio Virtual Cable)` | **13** | Windows DirectSound |
| 同上（最低延迟） | `CABLE Input (VB-Audio Virtual Cable)` | **16** | Windows WASAPI |
| 桥接程序录音 | `CABLE Output (VB-Audio Virtual Cable)` | 2 / 9 / 18 | MME / DS / WASAPI |
| 本机外放（默认） | `扬声器 (Realtek(R) Audio)` | 4 | MME |

> 三个 Host API 是同一个物理端点的三套驱动接口。试听优先选 **WASAPI**（延迟最低），
> 桥接对延迟不敏感，MME 也可以。
>
> 索引会随插拔变化，程序里不要写死数字 —— 播放器的下拉每次展开都会重新枚举，
> 并按**名字**重新映射索引。

串口侧（`serial.tools.list_ports`）当前只有一条：`COM4  USB-SERIAL CH340`。

## 4. 怎么用

1. 先确认 COM4 在：设备管理器 → 端口，应出现 `USB-SERIAL CH340 (COM4)`。
2. 双击 `tool/启动FPGA声卡桥.bat`，窗口保持不关（它会打印桥接状态）。
3. 打开 `dist/ACX720VoiceChanger/ACX720VoiceChanger.exe`（或源码模式）。
4. 文件页底部的播放器一行，最右边新增了 **输出** 下拉：
   选 `CABLE Input (VB-Audio Virtual Cable)`。
   - 选「（系统默认）」= 声音走本机扬声器/耳机，用来快速试听；
   - 选 CABLE Input = 声音进 FPGA 那条链路，最终从单片机音响出来。
5. 播放时切换设备不会回到开头：位置保留，用新设备接着放。

## 5. 自检与判据

- `--selftest` 里有一项 `播放器可选输出设备`：用假 stream 拦下 `OutputStream`
  的实参，确认 `device` 真的透传下去了（不是只存了个变量）。
- `host/test_host.py` 的 `[20] 内嵌播放器` 也覆盖了「指定设备」和「切回系统默认」两条。
- 现场判断"到底走到哪一段"：
  - 播放器选 CABLE Input、桥接窗口有帧计数 → 数字链路通；
  - 单片机侧没声 → 问题在 DAC/功放/喇叭（先用 1 kHz 自检音，见
    `docs/音响检测_2026-10-20.md` 的排查顺序）；
  - 桥接报找不到 `CABLE Output` → VB-Cable 没装或被禁用。

## 6. 已知坑

- **不要把播放器输出设成"扬声器 (Realtek)"还指望单片机响** —— 那是两条完全不同的路。
- VB-Cable 的 `CABLE Input` 一旦被设成系统默认设备，整机所有声音都会进 FPGA；
  调试时容易误判"电脑没声音了"，用完记得切回来。
- 桥接是用 UART 传 24.414 kHz/16 bit 立体声，带宽接近 CH340 的上限，
  所以桥接窗口被关掉时不要指望还有声音。
