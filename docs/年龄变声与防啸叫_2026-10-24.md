## 二、防啸叫（AFC，不是 AEC）

先划清概念：AEC 需要一路参考信号；这里是「麦克风→变声→喇叭→又被麦克风收回来」的
闭环，没有参考，问题是**啸叫**，所以做的是 AFC。

算法：增长速率判据（同一 bin 每块涨 ≥3.5 dB 且足够响）或「连续 2 块快削顶」→
挂二阶陷波（Q 10~22，最深 −30 dB，最多 8 路）+ 按需限幅。

### 闭环实测（`python host/anti_howl.py`）
```
[PASS] T1  关闭时确实起振（负对照，峰值 5.06）
[PASS] T1b 开启后不再发散（0.59）
[PASS] T2  啸叫频点被压下 ≥12 dB（72.9 -> 39.1 dB）
[PASS] T3  人声基频附近变化 <6 dB
[PASS] T4  无啸叫时近乎透明（SNR 225.6 dB，陷波 0 个）
[PASS] T5  开关关闭时逐位直通（max|diff| = 0）
```
另外单独测过：语音峰值 0.3/0.6/0.8 全部 **0 陷波、SNR 232~241 dB**；
稳态纯音 300/1000 Hz 也不误判；性能 **0.02× 实时**。

### 这轮在它身上抓到的四个真 bug（都会重复出现）
1. **浅陷波写成了谐振器**：只缩放分子、分母不动，k=0 时极点没有零点抵消，
   在 f0 处 +35 dB —— 啸叫被放大 60 倍再喂回环路（峰值从 5.06 涨到 30.55）。
   改成**零极点半径配合**（零点半径从极点半径插值到 1），实测各深度增益
   −1.00/−3.01/−6.01/−12.01/−30.02 dB，任何频率都不超过 0 dB。
2. **新装的陷波在同一块里被删掉**：`cnt` 初值等于 `PERSIST`，保持循环立刻减到 0。
   改成三条独立规则（频段还响→加深；安静→宽限 25 块；宽限后再回退）。
3. **深度比较方向写反**：深度是负数，"浅到该撤"是 `depth >= OFF`，写成 `<=`
   导致每个 −12 dB 陷波一进来就被判"太浅"丢掉（notch 恒为 0）。
4. **兜底增益用谱电平判据**：环路一起振谱电平常年在 −12 dB 晃，duck 一直挂在
   −12 dB，人声被压 9 dB 且增长被压平 → 陷波永远装不上。改成**时域峰值**
   + 按需限幅（只压到 0.85 所需的量）。

## 三、配置解析 `rtl/cfg_parser.v`

包格式：`AA 55 | cmd | len | data | crc_lo crc_hi`，CRC16-CCITT（init FFFF, poly 1021）。
与音频帧 `A5 5A` 魔数不同，**并联在同一条 UART 字节流上**，不新增接收器
（一条 UART 只能有一个采样电路，否则两个接收器会各自对齐到不同起始位）。

实测：
```
P1 合法包 -> beta=20480 tilt=-6 breath=20 shim=30 en=1  ok=1 err=0
P2 CRC 错 -> 参数纹丝不动（仍是 20480），err=1          ← 负对照
P3 A5 5A 音频帧头 -> 不被误认，ok/err 都不变
P4 AA AA 55 重同步 -> 正确解析，ok=2
RESULT: ALL PASS
```

## 六、`rtl/age_core.v`（共振峰缩放）为什么还没交

这轮在它身上修掉了 8 个真 bug（指针未复位、RAM 初始化顺序、镜像 bin 未写、
除法器未预移、乘法位宽截断、累加器多驱动、清槽速度差 128 倍、判据脚本未应用延迟），
但 **β=1 透明性（R1）仍未通过**：直流输入稳态正确（8000→7988），
正弦重建的相关只有 0.77，且累加器里逐点值是 `x` 而不是 `x·w²`、各点叠加帧数在 1~2 之间跳。

结论：**当前实现不能接进顶层**（会让声音明显失真）。要交付这一半，需要把
`S_OLA` 的帧累加重写成可逐帧断言的更小结构，再用单脉冲/直流/正弦三级判据锁死。
在那之前，顶层只启用了 `age_tint` 这一半（气声/微颤/倾斜），共振峰不动。
