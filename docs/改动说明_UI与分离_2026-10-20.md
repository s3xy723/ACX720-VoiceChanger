# 上位机 UI / 分离调整（2026-10-20 22:50）

## 1. 变调只保留「FPGA 直算」

- 「变调」模块的引擎单选只剩一个：
  `FPGA 直算（时域延迟线）`
- 删除了「FPGA 内部小模型（频域提质）」选项。
- 旧配置文件里如果存了 `fpga_model`，`current_cfg()` 会强制回退到
  `fpga_direct`，不会再走到离线 HQ 变调分支。
- 文件模式变调现在统一走 `dsp.StereoChain` 的时域延迟线，和板子同源。

## 2. 本地模型分离面板精简

删除的控件：

- 人声变调（半音滑条）
- 共振峰保持
- RVC 目录 / RVC 模型选择

保留：

- 启用 AI 人声分离
- 分离质量
- 运算设备
- 声道路由（人声→左 / 伴奏→右，可反转）
- 人声音量 / 伴奏音量

`current_cfg()["ai"]` 里也删掉了 `semi/formant/voice/rvc_dir`，
`_split_worker` 不再做人声变调，避免分离后再变调引入 artifacts。

## 3. demucs 分离质量

文件模式不再用简化的 `ai_separate.separate` 旧实现，改为委托：

```
ai_separate.separate -> local_ai.separate
```

这样文件模式和实时链路共用同一套：

- sinc 重采样（不是线性插值）
- 模型 `segment` 自动处理
- CUDA OOM 自动缩短分段 / 回退 CPU
- 质量三档真正生效

### 新的质量档位

| 档位 | shifts | 段重叠 | 说明 |
|---|---:|---:|---|
| 快速 | 0 | 10% | 最快 |
| **标准（默认）** | **2** | **50%** | 2 次平移平均，明显比旧的 0/25% 干净 |
| 高质 | 4 | 50% | 4 次平移平均，最干净，耗时约 4× |

`shifts` 是 demucs 的时间平移等变平均：同一段音频平移推理多次再平均，
能压低分离残留；`overlap=50%` 让分段边界更平滑。

## 5. 建议

- 日常用「标准」；觉得还不够干净，切「高质」再跑一遍。
- 分离质量受源文件影响很大：128 kbps MP3 的伴奏残留通常比 FLAC 多。
- 如果只要人声/伴奏其中一路，把另一路音量拉到 0 即可。
