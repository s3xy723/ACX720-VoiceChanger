# 年龄变声：算法与 RTL 进展（2026-10-23）

需求：**做在「变调」模式下面，任意源年龄 → 任意目标年龄，不涉及分离。**

---

## 1. 设计要点：四个独立参数，不是"一个变调"

| 维度 | 物理对应 | 由谁负责 |
|---|---|---|
| 基频 r | 声带长度/张力 | `pitch_shift.v`（已有，r = 1 + dphase/64） |
| 共振峰 β | 声道长度/腔体 | `age_core.v`（STFT 包络缩放，**待写**） |
| 气声 | 声门闭合 | `age_tint.v`（已完成） |
| 微颤 shimmer | 神经肌肉控制 | `age_tint.v`（已完成） |
| 高频倾斜 | 组织松弛 | `age_tint.v`（已完成） |

**差分原则**：所有量都与"源年龄"作差，只有目标比源更老/更小时才有量。
所以 a0 == a1 时全部归零，输出必须与输入逐位相同 —— 这是"任意年龄"能成立的
前提，也是 `age_tint.v` 里 `en=0` 直通分支的由来。

**为什么换算放在上位机**（`host/age_model.py`）：曲线是对数插值，硬件做不了；
参数要能随时改、能跑测试。FPGA 只收 4 个定点数，接口稳定，RTL 不跟着曲线改。

**顺序不能反**：变调是重采样，会把共振峰一起乘 r。所以包络缩放要预先补偿，
传 `beta/r` 而不是 `beta`：

```
共振峰 × (beta/r) × r = beta      F0 × r
```

## 2. 已验证的部分（都可复跑）

### 2.1 `host/age_model.py` —— 年龄映射，25 条自检全过

```
python host/age_model.py
  PASS = 25  FAIL = 0
```

关键结论（都来自那一轮文献研究）：
- 男性 30→75 岁：r = **1.155**（+2.5 半音，**变老反而升高**）
- 女性 30→75 岁：r = **0.902**（−1.8 半音，**变老降低**）→ 男女音高差收窄
- 成人 30 → 儿童 8：r = 1.90（被安全区夹住）、β = 1.57
- 6 岁 → 40 岁男：r_raw ≈ 0.4，被夹到 **0.55** 并置 `clipped=True`
  （`pitch_shift.v` 在 r<0.53 时双抽头相位不相干，实测 r=0.375 有 3.8% 频率误差）

### 2.2 `tool/sim_age.py` —— 算法参考模型，10 条判据全过

```
python tool/sim_age.py selftest
  PASS = 10  FAIL = 0
```

| 判据 | 结果 |
|---|---|
| I1 β=1 恒等透明 | SNR **225 dB** |
| I2 包络缩放不改基频 | 120.0 → 120.0 Hz |
| I3 β̂ 误差 | 0.4% (β=1.15) / 1.2% (β=1.25) / 6.1% (β=0.90) |
| I3 负对照（未处理时 β̂） | 1.000 |
| I4 同年龄→同年龄 | max\|diff\| = 2.2e-16 |
| I5 定点量化后 SNR | 52.4 dB |

真实人声（分离后的 vocals，6 s）：

| 设定 β | 实测 β̂ | 误差 | F0 变化 |
|---|---|---|---|
| 0.88 | 0.905 | 2.8% | 287.3 → 290.1 Hz |
| 1.00 | 1.000 | 0.0% | 287.3 → 287.3 Hz |
| 1.15 | 1.115 | 3.0% | 287.3 → 288.2 Hz |
| 1.30 | 1.225 | 5.8% | 287.3 → 289.2 Hz |

完整链路 F0 比（源=同一段人声）：30→75 男 设定 1.155 / 实测 **1.163**；
8→30 男 设定 0.550 / 实测 **0.588**。方向与量级都对。

### 2.3 `rtl/age_tint.v` —— 时域音质着色，xsim 3 条判据全过

```
xvlog rtl/age_tint.v sim_src/tb_age_tint.v
xelab tb_age_tint -s tb; xsim tb -R
  [PASS] T1 en=0 逐位直通（比较 799 个样本，0 个不等）
  [PASS] T2 气声生效：800/800 样本改变
  [PASS] T3 倾斜分得开：亮=9.89e10 暗=9.47e09（比值 10.4×）
  PASS = 3  FAIL = 0
```

**负对照**：把 `dout <= en ? sat16(sum1) : x2` 改成忽略 `en`，
T1 立刻 **FAIL（797/799 不等）** —— 说明这条测试不是装饰。

资源与时钟：每样本 2 拍，预算 2048 拍；1 个 LFSR + 3 个乘法器量级，
预计 < 600 LUT + 3 DSP（**尚未综合，这个数字是估计值**）。

## 3. 这一轮踩到并修掉的坑（写 RTL 时最容易犯的）

1. **`{N{sign}, v}` 做符号扩展是无符号的**。拼接结果被零扩展，负数变成巨大正数，
   紧接着被 `sat16` 饱和成 +32767 —— 高频搁架整段变成直流偏移。
   现在统一改成 `$signed()` + 固定 36 位入参。
2. **测试台对齐差一级 = 假 PASS**。第一版在 `din_valid` 落下 8 拍后才检查，
   一个样本都没比过，"0 个不等"也报 PASS。改成连续 valid、逐拍比对，
   并显式打印**比较过多少个样本**。
3. **32 位 `integer` 累加平方和会溢出**（800 × 4e9 ≫ 2^31），
   溢出后 T3 的方向判据是完全错的。改成 `real`。
4. **系数全 0 时"处理路径"本身就等于直通**，所以那条直通测试当时是恒真的；
   必须 `en=0` 配**满系数**才能真正验到门控。
5. **全频带做包络缩放会炸**：高频段滚降陡，k/β 在 12 kHz 等于平移 2 kHz，
   补偿量 40 dB 以上，听感是尖啸。现在只在 **200–4500 Hz** 内移，
   两侧 0.35 倍频程余弦收口，单点补偿限 ±12 dB。

## 4. 还没做的（下一轮）

| 项 | 内容 | 预估 |
|---|---|---|
| `rtl/age_core.v` | 复用的 `fft1024/win1024`：包络（peak-hold 5 + log 平滑 25）→ 索引 `k/β` 插值 → 增益 → IFFT → OLA | ~600 行，1 天 |
| 配置通路 | FPGA 目前**完全不解析** `AA 55` 配置包（`uart_audio_rx.v` 只认音频帧头），要新增一个 cfg 解析器把 β/系数发进来 | ~150 行 |
| 顶层接入 | `voice_proc.v` 的 M_PITCH 支路串上 `age_core → age_tint`，dphase 改由配置给（拨码保留兜底） | 小 |
| 界面 | 「变调」模块加「源年龄 / 目标年龄 / 性别 / 强度」四个控件 | 小 |
| 上板验证 | 延迟从 52 ms 增至约 105 ms（STFT 1024 + OLA 1280 点），需实测确认可接受 | 小 |

**延迟要提前想清楚**：`age_core` 一进来，变调支路就多了约 52 ms，
加上 `pitch_shift.v` 自身的 84 ms，总延迟约 105 ms。做实时监听会明显拖后，
但做"演示 + 录音回放"没问题。
