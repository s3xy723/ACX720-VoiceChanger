# FPGA → 单片机全 SPI 链路 + MCP4922 DAC + PAM8403 接线指南（无 I2S 方案）

> 配套技术文档见《README_技术解析.md》。本版按你提供的《STM32F103C8T6引脚定义.xlsx》
> 重新设计：**全线不用 I2S**，FPGA→MCU 与 MCU→DAC 都走 SPI，全部引脚都在你
> 表格"默认复用功能"一栏内。
>
> 诚实备注：F103C8T6 芯片本身是有 I2S 的（I2S2=PB12/13/15，官方数据手册 DS5319
> 可查，你这张表是省略了 I2S 列的简化版）。但全 SPI 方案引脚功能更直白、逻辑
> 更简单，按本方案做完全成立。

## 0. 系统框图

```
 麦克风 ──► ES8388(板载ADC) ──I2S──► FPGA 变声处理(XC7A35T)
            （板载 codec 内部连线，与扩展口无关）      │
                                        │  spi_mirror_tx（新 RTL，替代 i2s_mirror_tx）
                                        │  SPI 主机：SCLK 2 MHz，每帧发 左/右 两个 16bit 字
                                        ▼
                     三根信号线 + GND（SCLK / CS̄ / MOSI）
                                        ▼
                            STM32F103C8T6
                             ├─ SPI1 从机接收（PA5=SCK，PA4=CS̄，PA7=数据）
                             │   EXTI4 检测 CS̄ 下降沿做左右声道同步
                             └─ SPI2 主机发送（PB13=SCK，PB15=数据，PB12=CS̄，PB0=LDAC̄）
                                        │  16bit 命令帧 ×2 / 声道对
                                        ▼
                            MCP4922 双通道 12-bit DAC
                                        │  VOUTA / VOUTB（0~3.3V，静音 1.65V）
                              两级 RC 低通 + 10µF 隔直
                                        ▼
                            PAM8403 功放（2×3W，D 类，5V 供电）
                                        │
                                ┌───────┴───────┐
                                ▼               ▼
                           3525 喇叭(左)   3525 喇叭(右)   4Ω / 3W × 2
```

## 2. MCP4922 引脚速查（14 脚 PDIP/SOIC，编号以 DS21897A 封装图为准；模块按丝印）

| 引脚名 | DIP 脚号 | 方向 | 接哪里 |
|---|---|---|---|
| VDD | 1 | 电源 | **3.3V**（从 STM32 板取），引脚旁 100 nF 去耦 |
| NC | 2 | — | 不接 |
| CS̄ | 3 | 输入 | STM32 **PB12**（GPIO 输出，空闲为高） |
| SCK | 4 | 输入 | STM32 **PB13**（SPI2_SCK） |
| SDI | 5 | 输入 | STM32 **PB15**（SPI2_MOSI） |
| NC | 6 | — | 不接 |
| NC | 7 | — | 不接 |
| LDAC̄ | 8 | 输入 | STM32 **PB0**（GPIO 输出）——左右同步锁存 |
| SHDN̄ | 9 | 输入 | **3.3V**（拉高禁止硬件关断，**不要悬空**） |
| VOUTB | 10 | 输出 | 右声道 → RC 网络 → PAM8403 R IN |
| VREFB | 11 | 输入 | **3.3V**（=VDD），对地 100 nF |

| VREFA | 13 | 输入 | **3.3V**（=VDD），对地 100 nF |

## 3. 接线表（一张表一个区域）

### 3.1 FPGA → STM32（SPI，4 根线）

| ACX720 GPIO0 排针 | FPGA 引脚 | 信号 | STM32F103C8T6 | 说明 |
|---|---|---|---|---|
| GPIO0-0 | **A13** | `mcu_sclk` | **PA5**（SPI1_SCK） | SPI 时钟 2 MHz，模式 0,0 |
| GPIO0-1 | **A14** | `mcu_nss` | **PA4**（SPI1_NSS） | 每个字 CS̄ 拉低一次；也接 EXTI4 做帧同步 |
| GPIO0-2 | **A15** | `mcu_mosi` | **PA7**（SPI1_MOSI） | FPGA→STM32 单向数据 |
| GPIO0 排针 GND | — | — | **GND** | **必须接，不共地全是乱码** |

> FPGA 侧需把 `i2s_mirror_tx.v` 换成 `spi_mirror_tx.v`（RTL 要点见技术解析 §3），
> `constr/voice_changer.xdc` 末节引脚号不变（仍是 A13/A14/A15），只改端口名
> 和注释。数据方向：SPI1 工作在全双工从机，但 MISO（PA6）**悬空不接**——
> 单向接收。

### 3.2 STM32 → MCP4922（SPI2 主机，4 根信号线 + 电源地）

| STM32 | MCP4922 | 说明 |
|---|---|---|
| **PB13**（SPI2_SCK） | **SCK** | SPI 时钟 4.5 MHz，模式 0,0 |
| **PB15**（SPI2_MOSI） | **SDI** | 16 位命令帧：4 bit 配置 + 12 bit 数据，MSB 先行 |
| **PB12**（GPIO 输出） | **CS̄** | 软件片选，空闲高、传输时拉低 |
| **PB0**（GPIO 输出） | **LDAC̄** | 左右两帧写完后拉低 ≥100 ns → 双通道同步更新 |
| 3.3V | VDD / SHDN̄ / VREFA / VREFB | SHDN̄ 必须拉高 |
| GND | VSS（第12脚） | 共地 |

> PB12 在 SPI2 从机模式才必须是 NSS；这里 SPI2 是主机，PB12 直接当普通
> GPIO 输出用（它本来就是双向 I/O）。

### 3.3 MCP4922 → PAM8403（模拟部分，左右各一路）

```
VOUTA(14) ──[4.7k]──●──[10k]──●──[10µF 电解,+朝左]──► PAM8403 L IN
                    │         │
                 [2.2nF]    [1nF]
                    │         │
                   GND       GND

VOUTB(10) ── 同样一套（4.7k/2.2nF/10k/1nF/10µF）──► PAM8403 R IN
```

| 元件 | 取值 | 作用 |
|---|---|---|
| 第一级 RC | 4.7 kΩ + 2.2 nF（fc ≈ 15.4 kHz） | 重建滤波，压制 24.4 kHz 采样镜像 |
| 第二级 RC | 10 kΩ + 1 nF（fc ≈ 15.9 kHz） | 二级滚降再衰 6 dB |
| 隔直电容 | 10 µF 电解（+ 端朝 DAC） | 静音时 VOUT = 1.65 V 直流（VDD/2），必须隔断 |

### 3.4 PAM8403 → 喇叭

| PAM8403 | 接哪里 | 说明 |
|---|---|---|
| **L+ / L−** | 左喇叭（3525）两根引线 | BTL 输出，**两端都不要接地** |
| **R+ / R−** | 右喇叭两根引线 | 两只喇叭极性接法保持一致（同相） |

喇叭线尽量短（<10 cm）并绞合，抗 D 类开关噪声。

### 3.5 供电与共地（最容易翻车的一节）

| 设备 | 供电 | 备注 |
|---|---|---|
| ACX720 | 板载 USB/电源 | 独立供电 |
| STM32 | ST-Link / USB / USB-TTL 3.3V | 独立供电；MCP4922 的 3.3V 从这里取 |
| MCP4922 | 3.3V（≤ 12 mA，可忽略） | VDD 旁 100 nF |
| PAM8403 | **外部 5V ≥1A 独立电源** | **绝不要从 FPGA/STM32 板取电** |

**共地（星型）**：FPGA GND、STM32 GND、MCP4922 VSS、PAM8403 GND 在面包板
同一根地轨汇成一点。PAM8403 电源去耦（100 nF + 470 µF）紧贴其 VCC 引脚。

## 4. 面包板布置建议

```
 [面包板地轨：所有 GND 汇于这里]
 ┌────────────────────────────────────────────────┐
 │  STM32(Blue Pill)    MCP4922        PAM8403    │
 │   PA5 ◄── SCLK       VOUTA ─[RC]─► L IN         │
 │   PA7 ◄── MOSI       VOUTB ─[RC]─► R IN         │
 │   PA4 ◄── CS̄(蓝)     SHDN̄/VREF×2 ── 3.3V 轨     │
 │   PB13 ──► SCK       L+/− ─► 左喇叭              │
 │   PB15 ──► SDI       R+/− ─► 右喇叭              │
 │   PB12 ──► CS̄(绿)                               │
 │   PB0  ──► LDAC̄(黄)                             │
 │   3.3V ─► VDD                                   │
 └────────────────────────────────────────────────┘
     ▲ SCLK/CS̄/MOSI 三根杜邦线（<20cm）
   ACX720 GPIO0-0/1/2 + GND
```

- FPGA→STM32 三根线 < 20 cm；STM32→DAC 四根线 < 15 cm（两段 SPI 都是
  低速率，但要防振铃）。数字线与喇叭线分开走。
- 裸 DIP 芯片跨面包板沟槽插放，100 nF 紧贴 1 脚（VDD）与 12 脚（VSS）。

## 5. 上电与首次开机顺序

1. 万用表蜂鸣档确认：FPGA/STM32/MCP4922/PAM8403 的 GND 全部互通（<1Ω）。
2. 上 FPGA 电、STM32 电、MCP4922 电（先不上功放）。
3. 万用表直流档测 VOUTA/VOUTB：静音时约 **1.65 V**（VDD/2，中值代码 2048）
   —— 不对就先查两段 SPI，别上功放。
4. PAM8403 电位器拧到最小，固件 `VOL_SHIFT` 先设 2（-12 dB）再编译。
5. 最后上功放 5V。对麦克风说话，慢慢加大到不破音。
6. STM32 串口（PA9/PA10，115200）看 `fs≈24414 Hz、ovr=0`。

## 6. 验收清单（Pass / Fail）

| # | 项目 | 怎么验 | 通过标准 |
|---|---|---|---|
| 1 | 共地 | 万用表蜂鸣：四块板 GND 互通 | 全部 <1Ω |
| 2 | FPGA→STM32 SPI 活动 | 频率档/示波器测 PA5 | 2 MHz 时钟突发（每帧 32 个） |
| 3 | CS̄ 帧节奏 | 测 PA4 | 每 20.5 µs 拉低一次（fs=24.414 kHz） |
| 4 | STM32 收流 | 串口 500 ms 一行 | `fs=24414` 左右，`ovr=0`（丢字计数） |
| 5 | STM32→DAC SPI 活动 | 示波器测 PB13 | 每 41 µs 两串 16 时钟脉冲 |
| 6 | DAC 静音中值 | 万用表测 VOUTA/VOUTB | 1.65 V ±0.1 V |
| 7 | LDAC 同步 | 示波器测 PB0 | 每 41 µs 一个窄低脉冲 |
| 8 | 隔直后无直流 | 测 10 µF 之后对地 | <50 mV |
| 9 | 双声道独立 | 上位机「分离」模式：人声只从左喇叭出、伴奏只从右 | 左右不串 |
| 10 | 左右同相 | 单声道测试音，两喇叭同进同出 | 无抵消感 |
| 11 | 不削波 | 大声说话听感 | 无爆裂失真 |

## 7. 故障排查

| 现象 | 最可能原因 | 怎么查 |
|---|---|---|
| 串口一个字都收不到 | 没共地 / 三根线插错 / FPGA 还是旧 I2S 位流 | 蜂鸣验地；确认 FPGA 已换 `spi_mirror_tx` 位流 |
| 收到字但左右乱跳 | EXTI4 帧同步没生效 | 示波器看 PA4 下降沿与 RXNE 对应关系 |
| VOUT 恒 0V | SHDN̄ 悬空；或命令字 SHDN 位=0 | 量 9 脚应为 3.3V；查 0x3000/0xB000 |
| VOUT 恒 1.65V 不动 | SPI2 没写进去（CPOL/CPHA 配错） | 确认 SPI2 模式 0,0；示波器看 PB13 有无脉冲 |
| 输出到中值以上就削顶 | GA 位写反（2× 增益削半 VREF=VDD 信号） | 确认 bit13=1（1× 增益，0x3000/0xB000） |
| 有声但"沙沙"金属味 | SPI 位错位（飞线过长/虚接） | 看串口 `ovr`；缩短线、按压排查 |
| 只有单边 | 一路 RC 虚接 / LDAC 只写了一个通道 | 交换 VOUTA/VOUTB 接线定位 |
| 破音 | DAC 满幅 × PAM8403 24 dB 增益过载 | 电位器调小 / `VOL_SHIFT=2` |
| 嗡嗡声（50 Hz hum） | 地环路 / 功放电源差 | 加 470 µF 去耦；检查星型共地 |
| 声音闷 | 采样率 24.414 kHz 的正常表现 | 想更亮改 ES8388 到 48 kHz（技术解析 §8） |

## 8. 飞线规范与线材

| 线 | 要求 | 原因 |
|---|---|---|
| FPGA→STM32 三根（A13/A14/A15） | <20 cm，杜邦即可 | 2 MHz；过长振铃采错位 |
| STM32→DAC 四根（SCK/SDI/CS/LDAC） | <15 cm | 4.5 MHz 突发；CS/LDAC 边沿要干净 |
| 喇叭线 | <10 cm，两根绞合 | D 类 250 kHz 开关电流防辐射 |
| 模拟信号（VOUT→功放） | 远离数字飞线 | 防串扰 |
